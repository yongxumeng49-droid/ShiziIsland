# 识字小岛

给小学一、二年级孩子用的 iPad 认字应用。孩子看字、听读音、做选择题和配对，不需要账号，也不需要联网。

## 这一版做什么

- 四个阶段：启蒙、基础、进阶、拓展。启蒙一开始就开着，后面的阶段要走完前一阶段的全部小岛才打开。
- 每个阶段按字表分成小岛。一座岛最多 50 个字，分成每课 5 个新字；最后如果不够 50 或不够 5，就留在该阶段、该岛的最后一课，不丢字。每座岛学完有一次小岛测验。
- 新课先认识这 5 个字。拼音写在汉字正上方，字号更大，旁边有一张卡通图。卡片出现就会自己读：这个字读三遍，中间停大约 0.7 秒，接着读词语和短句。按钮还可以再听。
- 然后做大约 8 到 12 道练习，四种题都会出现：看字选拼音、听音选字、看拼音选字、配对。听音选字也会自动把字读三遍。
- 答对会轮流说一句短表扬：「真棒！」「对啦！」「太厉害了！」「真聪明！」「做得好！」「完全正确！」答错不表扬。没有爱心，也不会因为错了就把孩子锁在外面。
- 首页有设置：可选声音、每天学几个新字、关于。没有一键清空进度。
- 默认每天 5 个新字（一课），也可以选 10 个（两课）。只算新字。今日复习、小岛测验、已经学过的课都不占名额。当天新课学完了，要到明天才打开下一课新字。
- 星星、连续学习天数、每个字的复习时间都记在这台 iPad 上。下次打开还在。以前存下的进度还能读。
- 已经学完的课可以再认一次。离开认字或复习页面时，朗读会停，不会在背后一直播。

## 这一版不做什么

- 不写字，不描红，不考笔顺。
- 不注册，不登录，不上传进度。

字表里 `hidden` 为 true 的字不会出现在小岛和练习中。

## 拼音和插图

认新字、复习里再认一个字时，拼音在汉字的正上方，用更大的字号，像课本那样。看字选拼音的题目不会把拼音一起显示出来，不然答案就露了。

每个正在学的字都有一张给孩子看的卡通图。启蒙第一座岛的 50 个字有各自的图，从「的、是、在、了、我」到这一岛的最后一个字「多」（编号 1 到 50，资源名 `Hanzi0001` 到 `Hanzi0050`）。后面的字先共用分类图：人物、自然、家里、动作、东西；对不上的用一张故事书图。画面是温和的儿童绘本，没有吓人的内容，也没有宗教画面。

字表可以以后加一个可选字段 `illustration`，填资源名。没填的时候仍按编号和分类来。这一版没有重排、也没有改写字表里原有的字、拼音和句子。

## 设置和每日计划

首页右上角是「设置」。

- 声音：童声1、童声2、老师，默认童声1。点喇叭听这一档的样音。
- 每日计划：每天 5 个新字或 10 个新字。阶段仍然要走完上一阶段才打开。同一阶段里，新字不会无限往后解锁。
- 关于：应用是做什么的。这里没有清空进度的按钮，避免孩子随手点掉。

只统计新字。打开一课还没学过的新字时，这些字就算进今天。已经学完的课再认一次、小岛测验、今日复习，都不占名额。名额用完，或者剩下的名额不够下一整课，新课会停在「今天学完啦 / 今天先到这里」，要到第二天再开。复习一直可以做。

## 声音

三档名字是 童声1、童声2、老师。包里已经放了三段样音，只在设置里试听：

| 声音 | 文件 | 内容 |
| --- | --- | --- |
| 童声1 | `ShiziIsland/Resources/Voices/child1/preview.m4a` | 童声念《画》 |
| 童声2 | `ShiziIsland/Resources/Voices/child2/preview.m4a` | 另一个童声念《画》 |
| 老师 | `ShiziIsland/Resources/Voices/teacher/preview.m4a` | 老师说的鼓励 |

这三段是音色样音，不是整本字的录音。字音、词语、短句，以及答对后的六句表扬，这一版还没有按这三个音色配好的录音，会先用这台 iPad 自带的普通话语音，完全离线。选童声时音调高一点；选老师时用普通音调，有女声就优先女声。不使用付费语音，也不联网合成。

以后可以把 m4a 放进对应目录，有文件就播文件，没有才用系统语音：

- `Voices/child1/`、`Voices/child2/`、`Voices/teacher/`
- `char/1.m4a`：编号 1 的字，也就是「的」
- `word/1-0.m4a`、`word/1-1.m4a`：这个字的第一个、第二个词语
- `sentence/1.m4a`：这个字的短句
- `praise/0.m4a` 到 `praise/5.m4a`：依次是「真棒！」「对啦！」「太厉害了！」「真聪明！」「做得好！」「完全正确！」

## 在 iPad 上安装

需要一台 Mac、Xcode 15 或更新版本，以及 iPadOS 17 或更高的 iPad。用免费的 Apple ID 即可，不需要加入付费的 Apple Developer Program。工程里没有写死开发团队。

1. 在 Mac 上安装 Xcode（App Store 里免费下载），第一次打开时把需要的组件装完。
2. 用 Xcode 打开本目录里的 `ShiziIsland.xcodeproj`。如果 Xcode 提示升级工程格式，按它的建议升级即可。
3. 菜单 Xcode → Settings → Accounts，用你的 Apple ID 登录。登录后会出现一个 Personal Team。
4. 在左侧点最上面的工程 **ShiziIsland**，再点 TARGETS 下面的 **ShiziIsland**。
5. 打开 **Signing & Capabilities**。勾上 **Automatically manage signing**。在 **Team** 里选你的 Personal Team（名字一般是「你的名字 (Personal Team)」）。
6. 用数据线把 iPad 接到 Mac。iPad 上如果问是否信任这台电脑，点信任，并输入 iPad 密码。
7. Xcode 窗口顶部的运行设备选这台 iPad，点运行按钮（▶）。
8. 如果 iPad 上提示开发者不受信任：打开 **设置 → 通用 → VPN 与设备管理**（有的系统写成「设备管理」），点你的 Apple ID，选择信任。然后回到主屏幕，打开 **识字小岛**。

Bundle Identifier 目前是 `local.draft.shizixiaodao`。如果签名时提示这个标识已经被占用，可以在 Signing 里改成只属于你的名字，例如 `local.draft.shizixiaodao.mingzi`。不要把 Team 的编号写回仓库。

也可以在 Xcode 里选一台 iPad 模拟器运行，用来先看界面。装到自己的 iPad 上仍然按上面的步骤选 Personal Team。

## 字表

唯一字库是 `ShiziIsland/Resources/characters.json`，应用启动时读取，没有把三千个字写进 Swift。每条字段是：

| 字段 | 含义 |
| --- | --- |
| id | 编号，从 1 起 |
| char | 一个汉字 |
| pinyin | 带声调的拼音；轻声不加调号，例如 de、le、ma |
| strokes | 笔画数 |
| stage | 阶段，1 到 4 |
| hidden | 为 true 时，这个字不进入课程 |
| illustration | 可选。插图资源名。不写就用编号图或分类图 |

当前这份字表有 3000 个字，按常用程度排列，编号从 1 到 3000。启蒙从「的、是、在、了、我」开始。四个阶段的可学字分别是 749、745、745、747。标记 hidden 的字不会进入小岛和练习。拼音和笔画都以这份字表为准，应用不会另造。

每个可学的字另有两个词语和一句短句，读音跟着这条的拼音走。例如：的（de）是「是的 / 好的」，句子「你也是我的人」；是（shì）是「不是 / 是的」；在（zài）是「现在 / 正在」；了（le）是「好了 / 来了」；我（wǒ）是「我们 / 我的」。长在字表里是 zhǎng，词语用「长大 / 生长」，不用「长城」。行是 xíng，词语用「行走 / 行人」，不用「银行」。

首页有「今日复习」。到期的字按大约 10 分钟、1 天、2 天、4 天、7 天、15 天、30 天再出现。答错会回到短间隔。读音先找当前声音目录里的录音；还没有录音时，用这台 iPad 的普通话系统语音。这些都不需要联网。

## 本地进度

星星、完成了哪几课、连续天数、每个字的复习盒子，以及每天新学了哪些字（`newCharacterDays`），写在这台设备的 Application Support/ShiziIsland/progress.json。以前没有 `newCharacterDays` 的进度文件仍然能打开，不会被清掉。声音和每天学几个字记在本机偏好里。删掉应用就会一起删掉。
